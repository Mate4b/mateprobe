# Changelog

## 0.1.0a1 — 2026-09-28

Initial alpha: branch-scoped state contracts, explicit unknown/error outcomes, configurable
heuristic policy, lexical rules, reproducible JSON reports, attributable mutation audits,
positive-control preservation metrics, optional pytest plugin, CLI, LifeCard adapter,
synthetic feasibility corpus and a research draft with an independent evaluation protocol.

Known limits: arbitrary-text entailment, semantic paraphrase, negation and quotation are
not solved; all benchmark labels are authored; distributed pytest reports are unsupported.
